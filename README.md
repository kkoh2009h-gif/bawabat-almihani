# بوابة المهني

موقع عربي باتجاه RTL يهدف إلى تنظيم معلومات التعليم المهني في العراق: الأقسام، الكتب والمناهج، الكليات والمعاهد، وضوابط القبول.

## الحالة الحالية
هذه نسخة أولية للواجهة (Prototype)، وتحتوي على بحث محلي وقائمة محافظات وحاسبة استكشاف توضيحية. **لا تحتوي بعد على قاعدة بيانات رسمية للمناهج أو معدلات القبول**، ولا ينبغي اعتبار أي عنصر فيها قرار قبول أو معلومة وزارية مؤكدة.

## تشغيل الموقع
- الصفحة الرئيسية موجودة في `index.html`.
- لا توجد حاجة إلى Node.js أو أدوات بناء؛ الموقع ثابت ويعمل على الهاتف.
- للنشر: افتح **Settings → Pages**، ثم اختر **Deploy from a branch**، وحدد `main` والمجلد `/(root)`، ثم احفظ. بعد اكتمال النشر سيظهر رابط الموقع في إعدادات Pages.

## الخطوات التالية
1. توثيق أسماء الأقسام والانتقالات من أدلة وزارة التربية الرسمية.
2. جمع الكتب وروابط المناهج مع السنة الدراسية ومصدر كل رابط.
3. جمع دليل القبول الرسمي للكليات والمعاهد حسب القسم ونوع الدراسة والسنة.
4. ربط الحاسبة ببيانات موثقة مع إظهار سنة المصدر والتنبيه إلى أن القبول النهائي من الجهات المختصة.
