# بوابة المهني

موقع عربي باتجاه RTL لتنظيم معلومات التعليم المهني في العراق، ومساعدة الطلبة على الوصول إلى مصادر المناهج والأقسام وأدلة القبول الرسمية.

## صفحات الموقع

- `index.html` — الصفحة الرئيسية والبحث والاستكشاف الأولي.
- `colleges.html` — دليل تمهيدي للكليات والمعاهد وروابط مصادر القبول.
- `curricula.html` — مكتبة أولية لروابط كتب PDF وصفحات الفروع المهنية، مع بحث وفلترة حسب الصف.
- `departments.html` — دليل أولي للأقسام والفروع المهنية.
- `announcements.html` — ملخصات وروابط لإعلانات القبول الرسمية.
- `data/curricula.json` — سجل أولي لكتب ومناهج مع بيانات المصدر.
- `data/departments.json` — هيكل بيانات الفروع والأقسام.
- `data/admissions.json` و`data/acceptance-pathways.json` — هياكل أولية لتوثيق بيانات القبول؛ ليست قاعدة قبول مكتملة.
- `data/README.md` — قواعد توثيق مصادر البيانات والتحقق منها.

## الحالة وحدود الدقة

الموقع قيد التطوير. بعض الروابط تؤدي إلى صفحات الفروع العامة، وفهرس الكتب غير شامل، وقد تختلف الطبعات بحسب الصف والسنة الدراسية. لا توجد حالياً قاعدة مكتملة وموثقة للحدود التنافسية أو أهلية كل قسم، لذلك لا تُعد الصفحات أو الحاسبة التوضيحية نتيجة قبول رسمية.

قبل نشر أي معلومة عن القبول، يجب تسجيل سنة الدليل ومصدره وصفحته، والتمييز بين:
1. أهلية خريج الفرع للتقديم.
2. الحد الأدنى المسموح للتقديم إن وجد.
3. الحد التنافسي الفعلي للقبول.

لا تُستخدم حدود سنة سابقة على أنها حدود السنة الحالية. تُراجع المعلومات عبر وزارة التعليم العالي والبحث العلمي ودائرة الدراسات والتخطيط والمتابعة، وكتب المديرية العامة للتعليم المهني.

## المصادر الرسمية

- وزارة التعليم العالي والبحث العلمي: https://mohesr.gov.iq/
- بوابة دائرة الدراسات والتخطيط والمتابعة: https://dirasat.mohesr.gov.iq/
- مركز تحميل الأدلة: https://dirasat.mohesr.gov.iq/download-center.html
- المديرية العامة للتعليم المهني: https://vocational.edu.iq/

## تشغيل ونشر الموقع

الموقع ثابت ويعمل على الهاتف، ولا يحتاج إلى Node.js أو خطوة بناء. يستضيفه GitHub Pages من الفرع الرئيسي ومجلد الجذر إذا كانت إعدادات Pages مضبوطة على ذلك.

## الهوية

**بوابة المهني** منصة تعليمية مستقلة لخدمة طلبة التعليم المهني في العراق، وليست تابعة لجهة حكومية أو جامعة.
