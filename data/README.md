# إدارة البيانات الرسمية في بوابة المهني

يُستخدم الملف `data/admissions.json` كفهرس أولي للمصادر وهيكل بيانات. لا تُملأ مصفوفتا `admissions` و`curricula` بمعلومات تخمينية.

## حقول مقترحة لكل سجل قبول
- `academicYear`: السنة الدراسية مثل `2026-2027`.
- `department`: اسم الفرع أو القسم المهني كما ورد في الدليل.
- `institution`: اسم الجامعة أو الكلية أو المعهد.
- `program`: اسم التخصص أو القسم.
- `studyType`: صباحي أو مسائي أو أهلي، فقط إذا نص المصدر على ذلك.
- `eligibility`: شروط التقديم كما وردت، مع الحفاظ على الاستثناءات.
- `minimumAverage`: لا يُملأ إلا إذا نشر المصدر حداً أدنى واضحاً؛ لا تخلط الحد الأدنى للتقديم مع الحد الفعلي للقبول التنافسي.
- `sourceTitle`, `sourceUrl`, `sourcePage`: عنوان المصدر والرابط ورقم الصفحة عند توفره.
- `verifiedOn`: تاريخ آخر تحقق.
- `notes`: ملاحظات أو قيود ضرورية.

## قواعد النشر
1. استخدم دليل السنة الدراسية نفسها، لا نسخة قديمة إذا نُشرت نسخة أحدث.
2. افصل بين شروط الأهلية، والحد الأدنى للتقديم، والحدود الدنيا الناتجة عن المنافسة.
3. لا تستنتج أن تخصصاً يقبل خريج قسم مهني ما لم يذكر الدليل ذلك صراحة.
4. إذا تعذر التحقق، اعرض عبارة «قيد التحقق» ولا تعرض النتيجة كحقيقة.
5. احتفظ برابط المصدر وتاريخ التحقق بجوار كل معلومة قابلة للتغير.
6. لا تجمع بيانات شخصية للطلاب في ملفات المستودع.
